== hibernated ==
 paguro

   Windows saved a session -- starting Linux read-only

   This is normal after shutting Windows down. Your disk is fine. Linux will
   start, but cannot write until Windows resumes once.

   [Enter]  Continue read-only -- get to your files
   [W]      Restart into Windows -- then restart into Linux














   [F5] language   [F3] graphics

== dirty ==
 paguro

   Windows didn't shut down cleanly last time

   This is usually harmless and your disk is fine. Linux will start read-only
   until Windows has started and shut down once.

   [Enter]  Continue read-only -- get to your files
   [W]      Restart into Windows -- then restart into Linux














   [F5] language   [F3] graphics

   paguro refuses it. Start Windows and run the paguro repair tool.

== path-typing ==
 paguro
   ! Unattested -- paguro could not verify its configuration

   Type the path of what to start

   Path
   > \paguro\rescue.efi

   Keyboard: English (US)

   A path on this volume, such as \paguro\debian.vhd. A name ending in .efi
   starts as a UEFI application.

   / works as well as \. A drive letter such as C: is ignored: the path is on
   the volume you chose.

   [F3] graphics
